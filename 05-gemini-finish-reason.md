# Gemini finishReason and blockReason

Gemini puts a `finishReason` on each candidate, and when the prompt itself is blocked there are no candidates at all, only `promptFeedback.blockReason`.

The reference gives no per-value action, so every action below is a house recommendation.

| finishReason | Reference | House action |
|---|---|---|
| `STOP` | "Natural stop point of the model or provided stop sequence." | Use |
| `MAX_TOKENS` | "The maximum number of tokens as specified in the request was reached." | More room |
| `CONTINUATION` | reached "the per-request token limit, but generation is not yet complete" | Continue with the returned `continuationToken` |
| `SAFETY`, `RECITATION` | content "flagged for safety reasons", "for recitation reasons" | Show the user |
| `LANGUAGE` | "flagged for using an unsupported language" | Show the user |
| `BLOCKLIST`, `PROHIBITED_CONTENT`, `SPII` | "forbidden terms", "potentially containing prohibited content", "Sensitive Personally Identifiable Information (SPII)" | Show the user |
| `MALFORMED_FUNCTION_CALL` | "The function call generated by the model is invalid." | Fix the request |
| `UNEXPECTED_TOOL_CALL` | "no tools were enabled in the request" | Fix the request |
| `TOO_MANY_TOOL_CALLS` | "Model called too many tools consecutively" | Fix the request |
| `MISSING_THOUGHT_SIGNATURE` | "at least one thought signature missing" | Fix the request |
| `IMAGE_SAFETY`, `IMAGE_PROHIBITED_CONTENT`, `IMAGE_OTHER`, `IMAGE_RECITATION`, `NO_IMAGE` | the image generation values, grouped | Show the user |
| `MALFORMED_RESPONSE` | "Finished due to malformed response." | Fall back |
| `ESCALATION` | "filtered by an escalation rule" | Show the user |
| `PUP_LIMITED_DISABLED` | account "limited or disabled due to Prohibited Use Policy (PUP) violations" | Show the user |
| `OTHER` | "Unknown reason." | Fall back |
| `FINISH_REASON_UNSPECIFIED` | "Default value. This value is unused." | Treat as unknown |

## Blocked prompts

`promptFeedback.blockReason`: "If set, the prompt was blocked and no candidates are returned. Rephrase the prompt." An empty `candidates` list is not an empty answer; read `promptFeedback`.

## finishMessage

"Details the reason why the model stopped generating tokens. This is populated only when finishReason is set."

Re-read the enum before you switch on it, and route any value you do not know to the unknown branch.
